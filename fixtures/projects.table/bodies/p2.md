# Table file format spike

Open, app-agnostic data-matrix file format. Sits in the same niche as
Airtable, Google Tables, and Obsidian Bases — a portable database that
also reads as a spreadsheet for information workers.

## Architecture

A `.table/` is a directory:

- `schema.json` — own schema vocabulary (not Frictionless-aligned)
- `rows.ndjson` — one JSON record per line, every row carries a system `id`
- `views.json` — saved views (table, kanban, gallery, list, calendar)
- `meta.json` — manifest, generator, timestamps
- `attachments/` — files referenced by row values
- `bodies/{id}.md` — optional long-form markdown bodies, Notion-style
- `index.sqlite` — optional rebuildable cache (gitignored)

## Goals

1. Information workers can move structured data between apps without
   lock-in. Plain text, line-diffable, greppable.
2. Workspace's wider thesis is local-first markdown plus structured
   data; `.table/` is the structured-data half.
3. Doubles as a `react-strict-dom` playground for the Workspace UI
   layer ahead of the Expo migration.
